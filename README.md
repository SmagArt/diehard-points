# Калькулятор баллов Die Hard

Считает баллы зачёта за воскресную длительную: дистанция + средний темп + твой
коэффициент. Один файл `index.html`, без зависимостей и без интернета —
открывается двойным кликом и работает офлайн.

**Живая версия:** https://SMAGIN.github.io/diehard-points/
_(подставится после включения GitHub Pages)_

## Что внутри

- ползунки дистанции (20–42.2 км), темпа (3:00–8:00/км) и коэффициента (1.0–2.0);
- галочка предварительной записи (+3 балла);
- блок «что выгоднее добавить» — километр против десяти секунд темпа;
- полная таблица баллов с подсветкой текущей ячейки;
- прогноз коэффициента при разной посещаемости.

## Правила, по которым считает

| Правило | Значение |
|---|---|
| Минимальная зачётная пробежка | 20 км и быстрее 7:00/км |
| Минимум баллов за зачётную | 5 |
| Медленнее 8:00/км | не учитывается вообще |
| Короче 20 км | считается пропуском |
| Успешная длительная | коэффициент +0.1 |
| Пропуск | коэффициент −0.2 |
| Диапазон коэффициента | 1.0 … 2.0 |
| Предварительная запись до воскресенья | +3 балла |
| Женский коэффициент | +10% к итогу |

Исходная таблица организаторов опубликована для коэффициента 2.0 — то есть это
потолок. База считается как `таблица / 2`, итог — `база × коэффициент`.

**Неуточнённое:** прибавляются ли +3 за запись до умножения на коэффициент или
после. Здесь — после. На сравнение вариантов между собой это не влияет.

## Как обновить

Правишь `index.html`, коммитишь, пушишь — Pages пересобирает страницу сам.
Данные таблицы лежат в константе `TABLE` внутри `<script>`, темпы — в `PACES`.

## Включить GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → Save.
Через минуту страница поднимется по адресу выше.
